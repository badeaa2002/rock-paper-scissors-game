# rock-paper-scissors-game
An interactive Rock Paper Scissors game built with HTML, CSS, and JavaScript, featuring single-player and multiplayer modes.
# Rock Paper Scissors Game

 Features
- Single Player Mode (Player vs Computer)
- Multiplayer Mode (Player vs Player)
- Interactive user interface
- Score tracking
- Game animations
- Game data stored using Local Storage

 Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

 How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Open the `start.html` file in your browser.
4. Choose your game mode and start playing!
